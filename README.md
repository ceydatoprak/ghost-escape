# 👻 Ghost Escape

A cozy mobile-friendly puzzle game prototype built with HTML, CSS and vanilla JavaScript.

You play as a small ghost trying to escape a mysterious house. Move through the shadows, possess objects, avoid humans and solve environmental puzzles across six different levels.

## Features

- 6 puzzle-based levels
- Object possession mechanic
- Light and shadow hazards
- Human patrol and detection system
- Hiding mechanics
- Keys, locked doors and pressure plates
- Movable objects and environmental puzzles
- Distraction mechanics using interactive objects
- Mobile touch controls
- Keyboard controls for desktop
- Procedural visuals and sound effects
- Level selection and restart system

## Gameplay

Each level introduces new mechanics and combines them with previous ones.

The ghost can possess different objects to interact with the environment. Some objects can disable lights, activate switches, distract humans or provide hiding places.

Later levels introduce more complex puzzles involving patrol routes, locked areas, movable objects and light manipulation.

## Controls

**Desktop**
- WASD / Arrow Keys — Move
- E / Space — Possess or interact
- Q / Esc — Release object
- 1–6 — Select level

**Mobile**
- Drag anywhere in the game area to move
- Use the on-screen action button to interact
- Use the level menu to select a level
